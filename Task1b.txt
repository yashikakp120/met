1. Two advantages compared to the readout in Exercise Sheet 3
--------------------------------------------------------------------------

Advantage 1: Reliable, adjustable and power-saving knock detection
  - Exercise 3: the piezo was read directly with P3IN by polling. A knock
    was only detected if the voltage crossed the digital input threshold
    at the moment the program checked the pin.
  - Exercise 4: a comparator compares the piezo signal with an adjustable
    threshold (potentiometer P1) and outputs a clean digital signal on
    COMP_OUT. This triggers an interrupt, so no knock is missed, the
    sensitivity can be adjusted, and the microcontroller can sleep in LPM4
    while waiting (lower power consumption).

Advantage 2: Separation of output and input path / protection of the pin
  - Exercise 3: one pin was used both as PWM output and as sensor input,
    so it had to be reconfigured all the time, and the piezo was connected
    directly to the microcontroller pin.
  - Exercise 4: the relay connects the buzzer either to the analog
    front-end or to the PWM pin. The two paths do not influence each
    other, and the piezo is no longer connected directly to the
    microcontroller, which protects the pin from voltage spikes of the
    piezo.


2. Signal flow
--------------------------------------------------------------------------

a) Sensing (relay OFF): knock -> microcontroller

   Piezo -> R6 -> X1 (BUZZER) -> CON4 middle -> relay -> CON4 right
   -> X2 (DAC_IN) -> R24 / R41 -> op-amp buffer -> comparator (vs. P1)
   -> R25 -> X7 (COMP_OUT) -> P1.3 (interrupt)

   A knock makes the piezo produce a voltage. With the relay off, this
   voltage reaches the analog front-end, is buffered, and is compared with
   the threshold. If it is higher, COMP_OUT goes high and the rising edge
   on P1.3 triggers an interrupt. The program counts the knocks within
   one second (1 knock = melody 1, 2 knocks = melody 2).

b) Playback (relay ON): microcontroller -> buzzer

   P1.0 -> X5 (REL_STAT) -> R11 -> T1 -> relay coil (relay switches)
   P3.6 (PWM, TA0.2) -> CON4 left -> relay -> CON4 middle -> X1 -> R6
   -> piezo

   The microcontroller sets P1.0 high, T1 switches on the relay, and the
   buzzer is connected to P3.6. Timer A0 generates the PWM signal and the
   piezo plays the melody. Afterwards P1.0 goes low, the relay switches
   back, and the buzzer is connected to the analog front-end again.


3. Significant components and their function
--------------------------------------------------------------------------

  Component             Function
  --------------------  --------------------------------------------------
  Piezo buzzer          Sensor: turns a knock into a voltage.
  (BUZZER1)             Speaker: turns the PWM signal into sound.

  Relay (RELAY1)        Switches the buzzer between the analog front-end
                        (relay off) and the PWM pin (relay on).

  T1 (BSS123)           MOSFET that switches the relay coil current,
                        controlled by REL_STAT.

  D13 (1N4148)          Freewheeling diode, protects T1 from the voltage
                        spike when the relay coil is switched off.

  R41 (1 MOhm, JP5      Discharges the piezo, so the signal returns to
  on VFO)               0 V after a knock.

  IC5A (TS912)          Voltage follower (buffer): high input impedance,
                        does not load the piezo; drives the next stage.

  IC5B (TS912)          Comparator: output high when the knock signal is
                        higher than the threshold.

  P1 (potentiometer)    Sets the threshold voltage = knock sensitivity.

  D8 (red LED)          Shows when the comparator output is high.

  R25 (10 kOhm)         Limits the current into the microcontroller pin.

  Timer A0 (TA0.2)      Generates the PWM signal (50 % duty cycle); the
                        period sets the frequency of each note.
